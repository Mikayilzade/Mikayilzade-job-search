# Job Search — Start Here

This repository is the source of truth for the autonomous job-search project.

## Goal
Find up to 100 **verified, realistically attainable** job opportunities for Mikayil in Baku or accessible from Azerbaijan, with target compensation of at least **2,500 AZN net/month equivalent**, preferably materially higher.

## Search philosophy
Search by transferable skills, not only by current title.

Candidate profile is defined in `PROFILE.md`.
Search and acceptance rules are defined in `SEARCH_RULES.md`.
Accepted opportunities are stored in `VACANCIES.csv`.
Rejected, expired, duplicate, or materially unsuitable opportunities are stored in `REJECTED.csv`.
Current progress and exact next action are in `STATUS.md`.

## Mandatory run procedure
1. Read `START_HERE.md`, `PROFILE.md`, `SEARCH_RULES.md`, `STATUS.md`, `VACANCIES.csv`, and `REJECTED.csv`.
2. Resume from `STATUS.md` → `NEXT ACTION`.
3. Search current public job sources and, whenever practical, verify the employer's own careers page.
4. Check activity/closing date, location/work model, realistic hiring from Azerbaijan, compensation evidence, skill fit, gaps, workload/risk, and application route.
5. Deduplicate against both accepted and rejected ledgers.
6. Add only defensible opportunities to `VACANCIES.csv`; record rejected/expired/uncertain leads in `REJECTED.csv` with a reason.
7. Update `STATUS.md` before ending the run.

## Categories
- `CORE`: direct or near-direct fit with current finance/AP/P2P/SAP/operations experience.
- `ADJACENT`: strong transferable-skill fit into a neighboring function.
- `STRETCH`: non-obvious role with a plausible path in and meaningful compensation/career upside.

## Completion condition
Search phase completes at 100 accepted, verified opportunities. Then move to ranking, CV variants, vacancy-specific tailoring, and application sequencing.
